# Ruby Dato Gem

This gem is forked from the official DatoCMS Ruby Gem, which is now archived and retired. This fork keeps the gem alive and maintained for a now smaller, more specialist, veteran set of users.

The goal of this fork is to keep the gem's basic functionality working and in step with Dato's current API. That is, the gem continues to be able to dump current, live Dato projects with full fidelity. The gem may contain historical code and features that veer outside of this; as development progresses we may prune those away. In general, maintaining compatibility is not a strong requirement, because very few users still use any version of this gem.

The maintained fork is distributed by direct Git repository reference. It cannot publish updates to the existing `dato` gem. Any future RubyGems publication will use a different package name chosen at that time.
